# Live sound setup

Runbooks and checklists I use for church services, weddings, and small events. This is a working handbook, not a product pitch: input lists, a gear inventory, a day-of-show flow, and a short troubleshooting sheet.

If you are borrowing these templates, copy a file, fill in your own inventory, and leave other people's names, addresses, and payment details out of the repo.

## Contents

- [Gear inventory](gear-inventory.md)
- [Church service checklist](checklists/church-service.md)
- [Wedding and event checklist](checklists/wedding-event.md)
- [Day-of-show runbook](checklists/day-of-show.md)

## How I use this

1. Update the inventory when a cable, mic, or box changes.
2. Before a service or event, copy the matching checklist and walk it in order.
3. After the show, note anything that failed or should be packed differently.

## What is not in this repo

No client addresses, phone numbers, invoices, unreleased recordings, or passwords for wireless or network gear. Those stay in a private note, not on GitHub.
